# 01_Biomimetic_oxidation_profiles.

This folder presents the complete set of analyzed molecules, including the observed biomimetic metabolite profiles, assigned structures, conversion rates, and MS values.

# 02_Biomimetic_oxidation_LCdata.

This folder contains the detailed chromatographic data for all biomimetic oxidation runs, including the LC-MS chromatograms and associated analytical outputs used for metabolite detection and comparison.

# 03_Statistics_MachineLearning.

This folder provides the extracted and cleaned dataset used for statistical modeling, together with the complete machine-learning workflow, source code, intermediate outputs, and final model results.

# 04_GLORYx.

This folder provides the GLORYx prediction results generated for the studied molecules using the GLORYx website API, including the reaction-type predictions used for external benchmark comparison.
